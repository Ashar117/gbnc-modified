# GBNC Modified Implementation

This repository is based on the public GBNC codebase associated with:

Shuyin Xia, Xinjun Ma, Zhiyuan Liu, Cheng Liu, Sen Zhao, and Guoyin Wang,  
**"Graph Coarsening via Supervised Granular-Ball for Scalable Graph Neural Network Training,"** AAAI 2025.

This modified implementation explores:
- score-based center selection
- neighbor exclusion for sparse center choice
- experiments with different purity thresholds

This work was developed as part of an undergraduate research project.
